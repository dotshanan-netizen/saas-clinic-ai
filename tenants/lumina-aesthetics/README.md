# Lumina Tenant

This folder is the official onboarding package for **Lumina Aesthetics**.

## Commands

**Validation (Dry Run)**
\`\`\`bash
npm run onboard --dry-run ./tenants/lumina-aesthetics
\`\`\`

**Production Deployment**
\`\`\`bash
npm run onboard --apply ./tenants/lumina-aesthetics
\`\`\`

**Rollback**
\`\`\`bash
npm run onboard --rollback lumina-aesthetics
\`\`\`
